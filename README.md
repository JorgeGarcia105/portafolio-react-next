# Portafolio Profesional - Jorge Iván García Torres

Este es el portafolio profesional de Jorge Iván García Torres, estudiante de Ingeniería de Sistemas y Computación en la Universidad de Caldas, desarrollador backend con experiencia en arquitectura de software, optimización de sistemas y soluciones Full Stack. El portafolio está construido con **Next.js 15**, **React**, **Tailwind CSS** y **TypeScript**, y desplegado en **Vercel**.

## ✨ Tecnologías principales

- **Next.js 15** (App Router)
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **framer-motion** (animaciones)
- **lucide-react** (íconos)
- **Vercel** (despliegue)

## 🛠️ Instalación y uso local

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/JorgeGarcia105/portafolio-react-next.git
   cd portafolio-react-next
   ```

2. **Instala las dependencias:**
   ```bash
   npm install
   ```

3. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

5. **Build para producción:**
   ```bash
   npm run build
   ```

## 🧭 Guía interactiva

El portafolio incluye una **guía interactiva** (Tour) para facilitar la navegación y destacar las secciones principales. El tour solo se activa al hacer clic en el botón correspondiente y nunca se abre automáticamente.

## 🌗 Tema claro/oscuro

El portafolio soporta tema claro y oscuro, alternable desde la barra de navegación. El tema se recuerda entre sesiones.
